# ✅ FINAL BURGUNDY COLOR SCHEME - WITH VISUAL HIERARCHY

## 🎨 Color Palette (Burgundy Primary with Depth)

### Primary Burgundy Variations:
- **#5C1D24** - Main Background (Primary sections, hero areas)
- **#7E2A33** - Cards & Elevated Surfaces (Lighter - creates CONTRAST)
- **#4A1720** - Alternate Sections (Darker - footer, deep sections)
- **#8B3541** - Hover States (Even lighter - interactive feedback)

### Text Colors:
- **#F3E9D2** - Primary Text (Beige - high contrast on burgundy)
- **#C8A165** - Secondary Text & Highlights (Gold - stands out beautifully)
- **#E8DCC4** - Muted Text (Darker beige - less emphasis)

### Buttons & CTAs:
- **#C8A165** - Primary Buttons (Gold - HIGHLY VISIBLE on burgundy)
- **#D9B77E** - Button Hover (Lighter gold)
- **#2E1E1E** - Button Text (Dark brown for readability)

### Borders & Dividers:
- **rgba(243,233,210,0.15)** - Subtle borders (Beige with opacity)
- **rgba(243,233,210,0.2)** - Dividers

## 📐 Visual Hierarchy Strategy:

### Layer 1 - Background (#5C1D24)
Main page background, primary sections

### Layer 2 - Elevated Surfaces (#7E2A33 - Lighter!)
Cards, modals, dropdowns - CLEARLY VISIBLE against main background

### Layer 3 - Alternate Sections (#4A1720 - Darker)
Footer, deep contrast areas

### Layer 4 - Interactive Elements (#C8A165 - Gold)
Buttons, links, CTAs - STAND OUT prominently
