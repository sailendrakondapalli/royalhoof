# HomePage Section Color Pattern

## Alternating Background Colors for Visual Separation

To create clear visual differentiation between adjacent sections, we use two burgundy shades:

### Color Palette:
- **Darker Burgundy**: `#5B1E28` - Main sections
- **Lighter Burgundy**: `#4A1720` - Alternate sections (slightly darker/more muted)

### Section Pattern (Top to Bottom):

1. **Hero Section** - Video background with overlay
2. **About Section** - `#5B1E28` (Darker) ✓
3. **Events Section** - `#4A1720` (Lighter) ✓
4. **Why Choose Us** - `#5B1E28` (Darker) ✓
5. **Our Packages** - `#4A1720` (Lighter) ✓
6. **Gallery** - `#5B1E28` (Darker) ✓
7. **Reviews** - `#4A1720` (Lighter) ✓
8. **Quick Contact** - `#5B1E28` (Darker) ✓
9. **Enquiry CTA** - `#4A1720` (Lighter) ✓

### Visual Result:
This alternating pattern creates a subtle wave effect that:
- ✅ Clearly separates adjacent sections
- ✅ Maintains the burgundy brand color throughout
- ✅ Creates visual rhythm and flow
- ✅ Improves readability and user experience
- ✅ Maintains elegant, premium feel

The difference is subtle but effective - visitors can easily distinguish where one section ends and another begins.
